Supermarket Sales Analysis Dashboard

Project Overview

This project analyzes supermarket sales data using Microsoft Power BI. The dashboard provides insights into sales performance, profit, customer behavior, product categories, and payment methods.

Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Excel / CSV

Dataset

The dataset contains supermarket transaction details, including:

- Invoice ID
- Branch and City
- Customer Type
- Gender
- Product Line
- Unit Price and Quantity
- Total Sales
- Payment Method
- Gross Income
- Customer Rating

Project Objectives

- Analyze overall supermarket sales.
- Identify top-performing product categories.
- Compare sales across different cities.
- Understand customer purchasing behavior.
- Analyze payment methods.
- Track sales performance.

Dashboard Features

- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Total Quantity Sold KPI
- Sales by Product Category
- Monthly Sales Trend
- Sales by City
- Payment Method Analysis
- Customer Type Analysis
- Interactive Slicers

Key Skills Demonstrated

- Data Cleaning
- Data Transformation
- Data Visualization
- DAX Calculations
- Business Intelligence
- Dashboard Development

Project Files

- supermarket Analysis.xlsx – Dataset
- SUPERMARKET SALES ANALYSIS.pbix – Power BI Dashboard

Conclusion

This project demonstrates how Power BI can be used to transform raw supermarket data into meaningful business insights through interactive dashboards and visualizations.
